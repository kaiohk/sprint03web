# JOVI Camera - Mind Core

Uma interface de câmera minimalista e inteligente, desenvolvida como entrega da sprint de Front-End. O projeto simula uma UI que se adapta ao jeito do usuário, utilizando armazenamento de estado e componentes dinâmicos para colocar as ferramentas mais usadas a um toque de distância.

## Tecnologias Utilizadas

- Next.js e React;
- Tailwind CSS;
- JavaScript;

## Como rodar o projeto localmente

Para testar a aplicação na sua máquina, siga o passo a passo abaixo:

**1. Pré-requisitos:**
Certifique-se de ter o **Node.js** instalado na sua máquina. Você pode verificar isso abrindo o terminal e digitando `node -v`.

**2. Preparando a pasta:**
Se você baixou o projeto em `.ZIP`, extraia todos os arquivos para uma pasta de sua preferência.
_(Se estiver clonando via Git, use o comando `git clone [link-do-repositorio]`)_.

**3. Abrindo o terminal:**
Abra o terminal (ou prompt de comando) e navegue até a pasta raiz onde o projeto foi extraído. Se estiver usando o VS Code, você pode simplesmente abrir a pasta do projeto e usar o terminal integrado (`Ctrl + '` ou `Cmd + '`).

**4. Instalando as dependências:**
Antes de rodar o projeto, é necessário instalar as bibliotecas que ele utiliza (como Next.js, React e Tailwind). No terminal, digite o seguinte comando e aperte Enter:

```bash
npm install
```

**5. Executando a aplicação:**
Com tudo instalado, inicie o servidor de desenvolvimento local digitando:

```bash
npm run dev
```

**6. Acessando no navegador:**
Após alguns segundos, o terminal exibirá uma mensagem informando que o servidor está rodando. Abra o seu navegador (Chrome, Edge, etc.) e acesse o seguinte endereço:

```
http://localhost:3000
```
